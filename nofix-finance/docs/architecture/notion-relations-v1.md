# Nofix Finance, Relações Nativas no Notion v1

## Objetivo

Amarrar as bases principais do fluxo de cartão no Notion com relações nativas.

## Relações desejadas

### Compras no Cartão
- relação com Cartões
- relação com Parcelas do Cartão

### Parcelas do Cartão
- relação com Compras no Cartão
- relação com Contas a Pagar

### Contas a Pagar
- relação com Parcelas do Cartão

## Benefícios

- rastreabilidade completa
- menos dependência de texto solto em observações
- base melhor para automações futuras
- melhor visualização operacional

## Observação

A criação de relações em databases já existentes no Notion via API pode exigir criação em duas pontas. Nesta etapa, o foco é estruturar essa evolução no schema e aplicar o que a API suportar de forma segura.
